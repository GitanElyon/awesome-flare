# Overview

This directory contains all the random one-off scripts and other assets I used to make qst possible. Currently, it only includes the python script I used to make the qst logo, but may be expanded upon later.

# Contents

## Titgle Generator

`titlegen.py` is the python script I used to generate the ascii text logo used at the top of the README in both the [qst](https://github.com/gitanelyon/qst) and the [awesome-qst](https://github.com/gitanelyon/awesome-qst) repos.
